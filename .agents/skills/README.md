# Project Skills

Place project-specific reusable agent skills in this directory when the project actually needs them.

Do not add skills merely to make the template look complete. A skill should represent a workflow that is repeated often enough to justify reusable instructions, scripts, references, or assets.

Example future structure:

```text
.agents/skills/
└── code-review/
    ├── SKILL.md
    ├── scripts/
    └── references/
```

The base template intentionally ships without project-specific skills.
